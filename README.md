# 超星学习通小助手（AI 答题版）

一款运行在浏览器油猴/脚本猫上的超星学习通辅助脚本。视频、文档任务自动完成，章节测试全部交给大模型作答，签到遇到人脸采集也能自动通过。界面是自绘的，不依赖任何外部 CSS 框架。

- 版本：`4.2`
- 作者：`xuchao3328`
- 许可：GPL-3.0-or-later
- 脚本文件：`chaoxing.js`

---

## 一、功能一览

| 功能 | 说明 |
| --- | --- |
| 视频任务 | 自动播放并按设定倍速推进，不加载视频文件本体，多开也不占网速 |
| 文档任务 | 自动完成文档浏览类节点 |
| 章节测试 | **全部题目由 AI 大模型作答**，无题库，支持单选 / 多选 / 判断 |
| 人脸验证 | 采集二维码参数后自动完成签到的人脸比对，无需本人出镜 |
| 自动跳转 | 一节完成后自动进入下一节，直到整章刷完 |
| 后台挂机 | 打开即激活，页面无需保持在最前 |
| 掉线重登 | 可选，检测到登录失效时用手机号密码自动登录 |
| 多端解除 | 可选，解除超星的多端学习监控 |

## 二、安装

### 1. 安装脚本管理器

推荐 **脚本猫（ScriptCat）**，其次 Tampermonkey / 油猴。

### 2. 添加脚本

新建脚本 → 把 `chaoxing.js` 的全部内容粘贴进去 → 保存。

### 3. 允许外部资源

脚本通过 CDN 加载 `crypto-js`（人脸验证签名要用到）。

> 若脚本管理器提示"是否允许访问外部网址"，选择**允许**；加载失败时人脸面板会明确显示"crypto-js 未加载"，而不是静默失效。

### 4. 开始使用

打开任意一门课程的章节页（地址含 `knowledge/cards`），脚本会自动接管页面并渲染控制面板。

## 三、AI 答题配置（核心）

章节测试没有题库，全部实时调用大模型。**不配置 AI 的话，答题功能无法使用。**

### 步骤

1. 面板 → **AI 答题配置** → 「选择模型」挑一个，接口地址和模型名会自动填好
2. 填入你自己的 API Key
3. 点 **测试连接**，日志显示"AI连接成功"即可

> 配置是立即落盘的，切换模型或点保存后会马上生效，刷新不会丢。

### 内置预设

| 预设 | 接口地址 | 模型名 |
| --- | --- | --- |
| DeepSeek（推荐·快） | `https://api.deepseek.com/chat/completions` | `deepseek-chat` |
| 小米 MiMo V2.5 | `https://api.xiaomimimo.com/v1/chat/completions` | `mimo-v2.5` |
| 小米 MiMo V2.5 Pro | `https://api.xiaomimimo.com/v1/chat/completions` | `mimo-v2.5-pro` |
| 自定义 | 手动填写 | 手动填写 |

脚本走的是 **OpenAI Chat Completions 兼容格式**，所以任何兼容该格式的服务都能直接用，例如通义、智谱、Kimi、硅基流动、本地 Ollama、自建中转站等。地址只填到 `/v1` 也可以，脚本会自动补 `/chat/completions`。

### 答题机制

- **按选项字母匹配**：提示词要求模型只返回选项字母，脚本按页面上的 `id-param` 精确点击对应项，不会出现"AI 说 A 却点到 B"
- **逐题串行**：同一时刻只问一道题，答完一道再发下一道，最稳也不容易触发风控
- **连续失败熔断**：连续 3 次请求失败会停止发题，避免刷爆额度
- **随机兜底**：某题 AI 没给出可用答案时，单选选 B、多选全选、判断选"错"（仅在正确率设置低于 100% 时启用）
- 串行数量和超时时间固定为 **1 路 / 30 秒**，面板不再提供调节，避免误设

## 四、面板说明

主面板打开后按功能分区：

### 任务配置

| 控件 | 作用 |
| --- | --- |
| 视频倍速 | 设定播放倍速。**高倍速有被清进度的风险，非必要建议保持 1 倍** |
| 自动答题 | 是否由脚本作答章节测试 |
| 自动提交 | 达到正确率要求时自动交卷 |
| 自动保存 | 未达要求或未开自动提交时，自动存草稿 |
| 复习模式 | 遇到已完成的视频任务不跳过，重新刷一遍 |
| 正确率（%） | AI 成功作答的题目占比达到该值才会提交，否则自动保存。想全部答对就设 100 |
| 暂停运行 | 一键暂停全部自动化动作，再点一次恢复。状态会记忆，刷新后仍是暂停 |

按钮左侧的小圆点是状态指示灯：**灰点=关闭，绿点=开启，橙点=已暂停**。顶栏的徽章也会同步显示"运行中 / 已暂停"。

### 任务列表 / 运行日志

右侧两栏实时显示当前节点的处理情况和脚本输出。日志带时间戳，超 50 条自动滚动淘汰，始终停在最新一条。

## 五、人脸验证

打开签到的人脸采集页（地址含 `/visit/stucoursemiddle`）后，右上角会出现浮动面板：

- **自动**：检测到页面后自行完成整条链路（取二维码参数 → 取上传凭证 → 拉取本人已备案人脸照 → 轻微像素扰动 → 上传换 objectId → 提交签到），失败最多重试 10 次
- **手动**：标题栏可拖拽挪位置，「提取参数」查看当前参数，「手动处理」立即执行一次
- 页面顶部会弹出提示条告知当前进度

## 六、脚本内的高级参数

这几个没法放到面板里，需要直接改 `chaoxing.js` 开头的代码，改完重新保存脚本。

```js
var jumpType = 1,        // 0:智能模式  1:遍历模式  2:不跳转
    disableMonitor = 0,  // 1:解除多端学习监控
    randomDo = 1,        // 1:AI 无答案时随机兜底（仅在正确率<100 时生效）
    backGround = 0,      // 1:对接「超星挂机小助手」脚本

    autoLogin = 0,       // 1:掉线自动登录（仅支持手机号+密码）
    phoneNumber = '',    // 手机号填在单引号之间
    password = '';       // 密码填在单引号之间
```

`jumpType` 是最常需要调的一个：默认遍历模式按顺序走每一节；如果出现不跳转或反复跳转，改成 `2`（不跳转）可彻底关闭自动前进。

## 七、常见问题

**用浏览器打开接口地址显示 405 Method Not Allowed**

正常现象。这类地址只接受 POST，浏览器地址栏用的是 GET，必然报 405——这恰恰说明服务器是通的。请一律用面板里的「测试连接」判断。

**测试连接失败，提示请求超时**

依次检查：① 本机网络能否访问该域名 ② 接口地址和模型名是否填错 ③ Key 是否有效、余额是否充足。默认超时是 30 秒。

**答题时报"AI未启用或未配置"**

说明 Key 没存上。回到课程主页面的面板重新填写并保存，刷新后再试。

**做到最后一节后脚本停下来**

这是正常的自动收尾。脚本通过检测页面上的「下一节」按钮是否可见来判断是否还有后续内容，判断前会重试若干次，避免页面没渲染完就误判。

**面板样式错乱**

界面样式全部内联在脚本里，不依赖任何 CDN。若出现错乱，多半是脚本没有完整粘贴。
